Aplicativo web para cadastrar, concluir e excluir tarefas, desenvolvido com Angular.

## Como baixar e executar

Requisitos:

- Node.js 20 ou superior
- npm

No terminal, execute:

```bash
npm install
npm start
```

Depois, acesse `http://localhost:4200/`.

Para gerar a versão de produção:

```bash
npm run build
```
